Plaats de logo-assets hier met deze bestandsnamen:

- `zuipopoly-logo-full.png` voor het grote ronde start/wachtkamer-logo.
- `zuipopoly-banner.svg` wordt nu gebruikt als tijdelijke vaste banner bovenaan alle schermen.
- Als je de definitieve PNG-banner wilt gebruiken, kan die later als `zuipopoly-banner.png` worden toegevoegd en in `src/main.js` worden gekoppeld.

De app heeft een tekstfallback zolang deze bestanden nog ontbreken.
